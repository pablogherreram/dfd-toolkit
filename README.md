# DFD Toolkit 🚀

A lightweight VS Code extension designed to parse, inspect, and translate classic `.dfd` (Diagramas de Flujo) files into modern formats. Built for students, developers, and educators working with algorithmic logic.

## ✨ Features
- **File Parsing & Diagnostics:** Read the internal token structure of legacy `.dfd` files.
- **Multi-Format Translation:** Automatically generate pseudocode, Mermaid charts, and structured JSON.
- **Seamless Integration:** Inspect logic right inside Visual Studio Code.

## 🛠️ Built With
- JavaScript / Node.js
- VS Code Extension API
